# App TEA Interactiva (frontend)

Interfaz estática en HTML, CSS y JavaScript pensada para tablets y móviles. Incluye las pantallas de dashboard de adulto, selector de módulo para el niño, ejercicio y progreso.

## Cómo usar

1. Abre `index.html` en tu navegador (mobile first, también responde en escritorio).
2. Usa los botones para navegar entre las vistas: inicio, módulos, ejercicio y progreso.
3. El código está listo para conectar a una API: reemplaza los textos y valores simulados por datos reales y añade eventos según sea necesario.

## Estructura
- `index.html`: Estructura de la interfaz y pantallas.
- `styles.css`: Estilos suaves con tipografía redondeada, botones grandes y diseño responsive.
- `script.js`: Navegación simple entre pantallas usando atributos `data-screen`.
